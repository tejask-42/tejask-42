# Tejas Kulkarni

I'm interested in machine learning systems research and classical ML methods, studying how models behave under real-world compute and scale constraints. I focus on understanding systems from first principles, investigating how algorithmic design, memory hierarchies, and infrastructure interact at scale.

---

### What I've Built

- **[ML Training Infrastructure](https://github.com/tejask-42/ml-training-infrastructure)** ([Live Documentation](https://tejask-42.github.io/ml-training-infrastructure))  
  An in-depth technical explainer and runnable implementation of Kubernetes-native ML pipelines with Argo Workflows and Apache Spark.

- **[XGBoost with Incremental Learning](https://github.com/tejask-42/XGBoost)**  
  Extended gradient boosted decision trees with in-place tree updating and statistical concept drift monitoring (Kolmogorov-Smirnov & PSI) on streaming tabular data, enabling continuous adaptation without expensive batch retraining.
